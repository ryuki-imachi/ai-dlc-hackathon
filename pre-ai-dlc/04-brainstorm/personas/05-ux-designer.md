# 林あかり（UXデザイナー・30歳）の頭の中

> 「ダメにする」を設計するなら、ホワイトハットな依存設計で、罪悪感を“解放”として体験させる。

---

- 読み終わって最初に思ったこと：これ、Hookedの教科書通りに4辺ハマってる。怖いくらい綺麗
- 外的トリガー（Slack催促）→ 行動（AIが断る）→ 変動報酬（ナマケといいね、AI褒め）→ 投資（連続記録）。ニール・イヤール笑顔
- 「サボる」ってネガを、ピーク・エンドの法則的に**称賛のピークで締める**設計が組み込まれてるのが強い。Pollyの優しい音声で「今日もよくサボれました」って言われた瞬間、記憶上は罪悪感→解放感に上書きされる
- でも提案書、**「初回起動から30秒で何が起きるか」が書かれてない**。これ致命的。SNSで一番大事なの、最初の3分の体験
- 空のタイムライン地獄問題を真面目に考えないとオンボで死ぬ。ダミーユーザーは“デモ用”じゃなくて“プロダクトの必須要素”
- 退会防止UXに「依存をデザインで強化」とだけ書いてある→これ要注意。FTCのClick-to-Cancelルールに引っかかる領域
- マイクロコピーの設計余地がデカすぎる。コピー10本書けばデモのウケ3割増す自信ある

## 感情の流れ（仮説：ペルソナ＝佐藤さん28歳SE・残業疲れ）

- **初回起動（0分）**：警戒＋好奇心。「個人情報抜かれる？」「会社にバレる？」が頭をよぎる。Slack連携要求でドロップ率50%超え見える。**ここに引き込む磁石を置く**＝Slack連携前にサボリ体験できるダミーモード
- **初日〜3日目（ハネムーン期）**：背徳的快感。AIに代返してもらった夜「あ、私やらなくていいんだ」の解放感。ここでドーパミン来てしまう。毎回同じ褒めだと慣れるから**変動比率強化スケジュール**で揺らす
- **1週間目（マンネリ谷）**：「もういいかな」が来る瞬間。アチーブメント解禁、文体ガチャ、サボリ偏差値で投資要素を増やす。ただしカジノ的なガチャ設計は本気のダークパターンになるから線引き必要
- **1ヶ月目（生活の一部）**：帰属意識ができてる。サボリ偏差値、コミュ内の地位。ここで質的リスク（本当に職を失う等）が出る。卒業モードを示唆しておく

## Hookモデル殴り書き

- **Trigger**：内的（めんどくさい／逃げたい／疲れた）が強烈に強い。これがこのプロダクト最大の資産。イヤール曰く「内的トリガーへの結びつけが完了したサービスはマーケ不要」。外的（Slack通知）は控えめでいい。**疲労時に通知爆撃するのは脆弱な瞬間を狙う設計＝NG**。クワイエットアワーズ必須
- **Action**：1タップで宣言できる摩擦の低さは◎。フィッツの法則的にもボタン位置サイズで詰められる。問題はSlack OAuthの2回タップ問題。ここに体験の崖がある。連携なしのライト体験を必ず置く
- **Variable Reward**：ここが私が一番熱くなる箇所。スキナーの変動比率強化が効くから、AI褒めは**長さ・文体・タイミングをランダム化**。短い「えらい」と長文の感動的な称賛をシャッフル。たまにPolly音声が降ってくる。**報酬の3層（自己×社会×物質）**のうち物質層が薄いから、解禁系報酬（バッジ／称号／文体ロック解除）を挿す
- **Investment**：連続記録47日＝47日分の自尊心が乗ってる。これを失うのが嫌で続ける＝サンクコスト。強力だが**退会困難の設計と紙一重**。データの引っ越し不可性で投資を強くするのは倫理的にギリギリ

## 行動経済学のレンズで気付いたこと

- **損失回避**：人は得より2倍以上「失う」のを嫌う（カーネマン）。47日連続記録は失いたくない資産。コピーは「今のリズムを失うと罪悪感に戻ります」より、「47日のサボリ実績を卒業モードで保管できます」のほうがホワイトハット
- **社会的証明**：「自分だけがダメではない」安心。タイムラインはここに直撃。ただしエコーチェンバー化したら現実適応力を奪う。**「ほどほどに頑張ってる人」も混ぜる**
- **ピーク・エンドの法則**：その日の体験はピークとエンドだけで記憶される。**夜の「今日のサボラーMVP」発表をエンドに置く**設計、これは天才。Pollyの優しい声で締める＝完璧
- **ザイオンス効果**：何度も触れるだけで好意度上昇。AI称賛キャラを擬人化（「サボリスト先生」とか）して毎日の褒めで愛着育てる
- **デフォルト効果**：AI自動返信をデフォルトONは行動経済学的には強烈に効く。けど個人情報的にもダークパターン的にもアウト寄り。**オプトイン＋誇張プレビュー**で誘惑するのがホワイトハット解
- **自己一致バイアス**：「あなたはサボリストです」とラベリングされた瞬間、ユーザーはそれに一致する行動を取り続ける（チアルディーニのコミットメント＆一貫性）。**初回オンボで「あなたのサボリ気質診断」入れると定着率跳ねる**
- **確証バイアス**：「サボってもいいんだ」を支持する情報ばかり集めてしまう構造になっている。これは確証バイアスを突いてる設計。便利だけど自覚的にやらないと事故る

## ダークパターン vs ホワイトハット（線引きノート）

- **依存設計＝ダークパターンではない**ことをまず確認。依存設計は中立、ダークパターンはユーザー利益を損ねる方向に振れたもの
- 「人をダメにする」というテーマは比喩であって、本気で人をダメにすることが求められてるわけじゃない（と私は読む）
- 黒寄りリストアップ：
  - 退会困難フロー → 完全アウト（FTC Click-to-Cancel 2024発効、EU DSA違反）
  - データを返さないロックイン → アウト（GDPRデータポータビリティ違反）
  - 罪悪感トリガー（「47日の友達ががっかりしています」）→ 感情ハッキング、NG
  - 疲労時のプッシュ通知 → 脆弱な瞬間を狙う、NG
  - 無限スクロール → 許容範囲。ただし「使いすぎ通知」は入れる
- **私の結論：「ネタとして振り切り、実装としてはホワイトハットに収める」のハイブリッド**。ホワイトハットでやろう
- 提案したいのは**「卒業設計（Off-boarding by Design）」**。サボリストは“サボることで自己受容ができ、いつかちゃんと戻る”サービスとして再定義
- 退会1タップ／データエクスポート（「サボリ47日の証明書」PDF出力）／「サボリスト名誉会員」として記録残す
- これ言えると審査員に「倫理的に深い」って思わせられる気がする

## マイクロコピー候補（思いつき殴り書き）

1. 「今日もよくサボれました」
2. 「おかえり、今日も逃げよう」
3. 「あなたは何もしなかった、それが正解」
4. 「言い訳はAIに任せて」
5. 「47日間、よく逃げきりました」
6. 「明日のあなたへ、今日のサボりが届きました」
7. 「ナマケ、いいよ」
8. 「えらい、今日も来なくて」
9. 「お疲れさま、何もせずに」
10. 「サボリ偏差値 72.3 — 上位3%」
11. 「いってらっしゃい。また疲れたら、戻っておいで」
12. 「Slackは見なくていい、私が見ておきます」

## 画面ラフ（ASCIIワイヤー）

ホーム画面。連続記録は**でかく**、丸ゴシック、ふんわり脱力系。背景は淡いベージュで頑張った形跡を消す色。

```
+----------------------------------+
|  [サボリスト]    [プロフ] [⚙]   |
|                                  |
|     47                           |
|     日連続でサボれています        |
|     今日もえらいね              |
|                                  |
|----------------------------------|
| @yamada が朝会をバックレました   |
|   AI「今日もよくサボれました」   |
|   [ナマケ 12]  [だらー 3]        |
|----------------------------------|
| @sato がメール3件放置             |
|   [ナマケ 5]                     |
|----------------------------------|
|  [+ 今日のサボリを宣言する]      |
+----------------------------------+
```

サボリ投稿画面：摩擦最小化。「朝会バックレ」「メール無視」「会議遅刻」のプリセット。フリー入力は折りたたみ。コピー：「言い訳はAIに任せて」

AI称賛モーダル（デモのキモ）：夜10時通知→タップで全画面占有→Polly音声が文字より先に来る→背景は深い藍色で星きらめく→Netflixの「次の話」前くらい没入。コピー：「お疲れさま。あなたは何もしなかった、それが正解」

退会フロー：1タップで遷移、引き留めなし。「あなたの47日のサボリは、PDFに保存できます」。コピー：「いってらっしゃい。また疲れたら、戻っておいで」

## 3分デモの演出メモ（秒単位）

- **0:00-0:10**：暗転スタート→Slackの「ピコン」→上司の催促「明日の朝会、出れる？」→観客「あー、わかる」と笑い始める
- **0:10-0:30**：主人公「めんどくさ…」→ローファイヒップホップで脱力→アプリ起動
- **0:30-1:00**：「朝会バックレ」タップ→AIの断り文がリアルタイムでタイプ→送信「シュッ」と気持ちいい効果音
- **1:00-1:30**：タイムライン→仲間の投稿が流れる→「ナマケ」が飛んでくるアニメ→観客「ズルい！」と笑う
- **1:30-2:00**：MVP選出のドラムロール→スポットライト→Polly「今日のサボラーMVPは……あなたです」
- **2:00-2:30**：47日→**48日**に更新の瞬間、数字がふわっと跳ねるマイクロインタラクション、星が舞う
- **2:30-3:00**：締めのコピー大写し**「あなたはもう戻れません」**→暗転→タイトル「サボリスト」
- 重要なのは**音と間（ま）**。Polly後に2秒の沈黙。会場が笑いから静まる。その「ゾクッ」を持ち帰ってもらう

## Inceptionで議論したいUX的問い

1. 佐藤さんは初日に何を見れば「これ、続けたい」と思うか
2. 空のタイムライン問題、ダミーユーザーは何人・どんな種類仕込む？
3. AI称賛コピー、感情曲線にどれくらいバラつきを持たせる？
4. Polly音声は1種類か複数選べるか。声で愛着が変わる
5. 連続記録が途切れた瞬間の体験は？罪悪感を与えるか、優しく受け止めるか
6. 習慣化の臨界は何日目？21日説、66日説、どっちで設計する？
7. 卒業モードは何をトリガーに発動する？
8. 退会フローのコピーは「引き留め」か「送り出し」か
9. 疲労時の通知制御（クワイエットアワーズ）はオプトインかオプトアウトか
10. 「サボリ偏差値」は他者比較か自己比較か
11. 上司・同僚に第三者バレした場合の体験設計（社会的リスク）
12. 若年層の倫理配慮、年齢制限の有無
13. Slack連携前にプロダクト価値を体験させるには何秒必要？
14. コンバージョン上の最大摩擦はどこ？（権限許諾／初回投稿／初回いいね受信）
15. 「あなたはもう戻れません」を最後の一撃にするか、それとも「いつでも戻れます」で締めるか——**プロダクトの倫理姿勢が一行で決まる問い**
